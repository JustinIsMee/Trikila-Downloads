# Trikila Android Downloads

Official pilot-testing downloads for Trikila Passenger and Driver.

## Download

- [Passenger APK v1.0.2](https://github.com/JustinIsMee/Trikila-Downloads/releases/latest/download/Trikila-Passenger.apk)
- [Driver APK v1.0.2](https://github.com/JustinIsMee/Trikila-Downloads/releases/latest/download/Trikila-Driver.apk)

## Install

1. Open this page in Chrome on your Android phone.
2. Download the correct app above.
3. Open the downloaded APK and allow installation from your browser if Android asks.
4. Install, or choose Update if you already have the same Trikila app.
5. Allow location access when needed. Drivers should enable Precise Location.

Android only. These APKs cannot be installed on iPhones. Pilot builds are still being tested.

## Pilot server

Downloading and installing does not require the operator laptop to be online. Logging in, booking and tracking require the Trikila pilot server to be running. If the temporary server address changes, ask the Trikila page for the current address and update Pilot server settings in the app. Older builds may contain an expired address.

This repository distributes APKs only. It does not contain user accounts, passwords, bookings, documents or application source code. Actual phone GPS and background notification behavior still needs device testing.
